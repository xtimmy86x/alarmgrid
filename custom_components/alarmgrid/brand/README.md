# AlarmGrid brand assets

The inherited upstream PNG files were removed for the AlarmGrid 2.0.0 clean break.
Before publishing, export the approved AlarmGrid artwork supplied by the project
owner to this directory using these exact filenames:

- `icon.png`
- `dark_icon.png`
- `logo.png`
- `dark_logo.png`

The exports must use the approved grid, warning triangle, waveform, dark navy,
alarm red, and white visual identity. Do not restore or reuse the former assets.
